# 新好友自动监听

2026-10-17：按用户要求，新好友无需逐个提供昵称登记。

## 工作方式

- `direct_enabled=true`、`direct_auto_discover=true`：每约60秒本地扫描最近会话。微信新好友/新私信进入最近会话后成为候选。
- 进入通讯录核验：通讯录选中图标、完整昵称、好友详情微信号及好友操作字段同时通过才登记，不用聊天内容或群名猜类型。
- 每轮最多核验3个未知会话；失败候选冷却5分钟，避免反复切界面。未知会话多时，接入可能需要数轮。
- 登记名单位于 WSL 的 `~/.local/state/wechat-bot/direct-friends.json`，不覆盖人工配置。重启机器人后仍有效。
- 收到消息才生成回复。新登记好友首次观察时只处理最后一轮入站、最多3条，不回放整段历史；既有会话规则不变。
- 发送前重新读取配置、黑名单及自动登记名单；黑名单立即撤销授权。群聊仍只允许原群白名单。
- 发现和纯轮询不调用模型；正常写回复的新消息识别沿用原策略。

## 保守边界

- OCR读不准、重名不同账号、资料页未核验、昵称截断：不猜、不登记，后续重试。
- 目前通讯录定位为有界4页查找；超出范围或特殊昵称需要继续适配，不能声称能识别任何昵称。
- 关闭 `direct_auto_discover` 只停止发现，已登记好友仍监听；关闭 `direct_enabled` 则私聊全部停用。
- 未改变朋友圈、图片、表情发送开关，未重启微信栈。
