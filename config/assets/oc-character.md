## 角色外观（生图提示词用）

一块奶白色方形年糕为主体，右上角有一小块咬痕；头戴宽檐绿色探险帽（棕色帽带 + 金色圆形帽徽）；
大眼睛、绿色瞳仁、张嘴笑，两颊有粉色红晕；背蓝色双肩背包（插着卷起来的铺盖卷）；
穿黄色探险靴；右手抬起挥手。整体是像素艺术（pixel art）风格，暖色调，治愈系，画面干净无文字。

## 使用规则

1. 生图时把上面的外观描述作为提示词前缀，保证每次画出来的是同一个角色；
2. 参考图本身通过 imagegen 的 ref_image 参数传入（缩放到 512px 以内再 base64）；
3. 如果 API 不支持参考图输入，文字描述 alone 也能稳定复现角色（qwen-image 对详细描述响应良好）；
4. 表情/姿势可随场景变化（挥手、惊讶、跑步、睡觉），但外观元素（年糕体、绿帽、蓝包、黄靴、咬痕）必须保留；
5. 不出现任何真实人名、地名、机构；不涉及时事政治。
